# docs/ — Deliverable Documentation

This folder holds **what 18Dragon ships**: the game's rules, player-facing
reference, and tooling documentation. It is *not* for planning.

- **Rules & player documentation** — the rulebook, reference cards, region guides,
  as they get written.
- **Tooling documentation** — notes on the 18xxMaker fork's custom features, if we
  document them for our own future use.

## Not here

Planning and tracking artifacts — PRDs, backlog, epics, sprints, stories, the
agile workflow — live in **`_artifacts/`**, not `docs/`. See
`_artifacts/workflow.md`.
